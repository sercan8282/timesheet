DEBUGGING BLOCK USER FUNCTIONALITY
==================================

Instructions:
1. Open http://localhost:3000 in your browser
2. Login as admin
3. Go to Admin → Users
4. Press F12 to open Developer Tools
5. Click on the "Console" tab
6. Copy-paste the following command and press Enter:

// TEST 1: Check if toggleBlockUser function exists
console.log("toggleBlockUser function:", typeof toggleBlockUser);

// TEST 2: Try to call it manually with userId=1, isBlocked=false
console.log("Calling toggleBlockUser(1, false)...");
toggleBlockUser(1, false);

// TEST 3: Check what's in a Block button's HTML
var blockBtn = document.querySelector("button:contains('Block')");
console.log("Block button:", blockBtn);
console.log("Block button onclick:", blockBtn ? blockBtn.onclick : "not found");
console.log("Block button HTML:", blockBtn ? blockBtn.outerHTML : "not found");
